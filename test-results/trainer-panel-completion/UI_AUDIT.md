# Trainer UI audit and screen inventory

2026-11-09 · Existing `/console` React/TypeScript/Vite application. All findings are limited to Trainer. Before images are the frozen pre-pass source served separately on port 3002 against the same isolated fixture API; after images use the implemented app on port 3000. Both authenticate through the normal Supabase client against the localhost-only provider.

## Inventory and preserved behavior

| Existing surface | Functionality preserved |
| --- | --- |
| Overview | Assigned-member counts, program gaps, attention filters, recent actual workouts, source-program shortcuts, create program. |
| Members | Search, attention/review filters, assigned-member selector, coach relationship, actual member schedules and future programs. |
| Member detail | Planned/completed/missed summaries, weekly comparison, planned/completed/extra exercise sets, historical workouts, performance filters, notes and contextual messages. |
| Programs | Source/member program lists, search/filter/status, duplication, history, preview, edit and assignment. |
| Program Builder | Title/settings, start/weeks, selected week/day, seven-day calendar, workouts, rest/unconfigured, duplicate week/day, validation, save/publish/version. |
| Workout Builder | Search/filter actual catalog, add/focus/configure, sets/reps/kg/time/distance/rest/notes, reorder/duplicate/remove/cancel/undo, template and day saving. |
| Publishing | Six persistent states, server confirmation, failure preservation/Retry, intentional rest days, incomplete-day navigation, explicit unpublish. |
| Assignment | Member selection, source version, dates, overlap impact, final review, independent member copies and existing assignment preservation. |
| Progress/reports | Completed-week reports, filtering, review/comment and honest unavailable/empty data. |
| Messages | Real member threads, context and send handlers. |
| New catalog surface | Existing authorized library data exposed as a searchable/filterable table, real movement instructions, selected-exercise-to-workout handoff. No catalog administration permissions added. |
