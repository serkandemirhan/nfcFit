## Completed in this follow-up
- Account IANA timezone editor in Settings, durable offline preference queue, server validation, account-zone report generation/daily wellness summaries/charts and new-program defaults. Existing plan schedules keep their own timezone.
- Authenticated daily missed-session reminders, active relationship/membership checks and recipient/session/date deduplication. Re-running a job does not reset an existing reminder's read state. The weekly-report worker checks the latest finished week daily, so western timezones are not missed by a single UTC Monday schedule.
- Native/web coach review filters for missed sessions, unreviewed changes, unread messages and pending reports. Web athlete analysis adds combined date/program/state filters and per-exercise actual-date charts with accessible tabular values. Missing weights are never estimated. Native report charts respect the selected facility.
- Explicit refresh of a future, empty, not-started prepared workout to current plan targets. CAS and stable request receipts protect retries/concurrent edits; started/past sessions and actual records never silently change. The mobile UI drains pending commands first and surfaces conflicts.
- Matching 384-key Turkish/English coaching resources and a static-label audit. This covers coaching resources, not full translation of legacy screens, server-generated prose, catalog instructions or user-authored content.
- Operator-only licensed-media validation/import workflow, transactional global-library updates, local checksum and provenance validation, disk-cached native images/animations, attribution and external video/3D opening. No licensed files were supplied; clean placeholders remain. See EXERCISE_MEDIA_WORKFLOW.md.
